# 📊 Call Center Performance Dashboard (Excel)

## 📌 Project Overview

This project focuses on analyzing call center data to track performance metrics and generate business insights using Microsoft Excel.

## 📁 Dataset

* Call Data (1000+ records)
* Customer Data (Gender, Age, City)
* Connected using Customer ID

## ⚙️ Tools & Techniques Used

* Microsoft Excel
* Pivot Tables & Pivot Charts
* Data Cleaning & Transformation
* Interactive Filtering (Representative-wise analysis)

## 📊 Key Features

* Total Calls, Revenue, Avg Rating, Customer Satisfaction
* Representative-wise performance analysis
* City-wise and Gender-based insights
* Call duration analysis

## 🔍 Key Insights

* Identified top-performing representatives
* Observed trends between call duration and customer satisfaction
* Compared revenue contribution across cities
